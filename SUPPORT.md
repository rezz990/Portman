# Support

For a reproducible bug, use the bug report form and include the Portman version, OS, exact command, expected port, steps, and redacted output.

For a feature, explain the workflow and the smallest useful behavior. Questions about a private project or a customer environment should remove credentials and personal paths before posting.

This project is maintained in spare time. A response is not guaranteed for unsupported Windows versions, protected/system processes, unsigned binaries, or commands that daemonize themselves.
